# Python Quiz Scoring Tool (أداة حساب درجات الاختبارات)

## Overview
This project is a concise Python script designed to practice and demonstrate the effective use of **loops (for/while)** and **accumulator variables**. Its primary function is to calculate the total score for a specified number of quizzes or student entries.

## File Details
* **File Name:** `Quiz_total_scorer.py`
* **Language:** Python 3

## Key Features & Techniques Used
* **Iterative Logic (Loops):** Uses `for` or `while` loops to repeatedly prompt the user for input (scores) without manual repetition of code.
* **Accumulator Pattern:** Implements a variable (e.g., `total_score`) to accumulate the scores from each iteration.
* **Input Validation:** Handles user input for the number of scores required.
* **Purpose:** To demonstrate a solid understanding of fundamental programming control flow related to repetition and data aggregation.
